🐍 Snake Water Gun Game

A simple command-line Snake Water Gun game developed using Python, where the player competes against the computer.

🎮 How to Play

Choose one of the following options:

s – Snake

w – Water

g – Gun

The computer randomly selects its choice, and the winner is decided according to the game rules.

✨ Features

Random computer selection.

User input handling.

Input validation.

Win, lose and draw detection.

Optimised winner determination using mathematical conditions.

🛠️ Technologies Used

Python

Random Module

▶️ How to Run

Clone this repository.

Open the project folder.

Run the following command:

python main_shortend.py
